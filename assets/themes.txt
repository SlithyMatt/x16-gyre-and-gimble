# Board color themes. A level picks one with "theme: NAME" (default: the
# first). All themes share one small family of hues: earthy stone, slate
# walls, peat-dark tunnels and a gold lit path, with the gimbal tints and
# the burrow kept recognizable. tools/shading.py turns each class color
# into a ramp of bevel and anti-aliasing shades. Gimbal teeth are drawn in
# their ring's stone color.
#
#   CLASS R G B   (0-15 per channel)
#
# Composite TV: tunnel < wall < stone < sel < lit must step up in luma by
# at least 1.5 each (the build checks), so the board reads in black and white.
#
# The garden around the board (tools/garden.py) has its own materials, each
# shaded from shadow to highlight: grass, hedge, four flowers (bloom1-4),
# paving under the text, the kerb around it, soil in the flower beds and the
# gravel path to the entry. Paving luma must be at most 3, under white text,
# and grass luma at least 1.5 from both paving and stone.
#
# "music NAME" picks the theme's tune, from assets/music/NAME.txt.
